# 初回の通しテスト — 見るところ

本番実装は別途稼働している。ここは**運用側が最初の1周を通すときに何を確認するか**をまとめたもの。

手順そのものはダッシュボードの取扱説明書 §5-12 に従う。本書はそれと重ねて読む「観点」の側。

---

## 通す前に決めておくこと（3件）

### 1. テストは私物LINEでよい。**本番グループは業務用アカウントで作る**

これだけは、作ってしまってからでは戻せない。

LINEの仕様上、**メンバーの強制退出・招待リンクの作り直し・投稿へのリアクション**は
botにはできず、人間の個人アカウントにしかできない。つまり**グループの運営権は、
そのグループを作ったアカウントが握る**。

担当者の私物LINEで本番グループを作ると、その人が辞めた時点で
招待リンクの発行権と強制退出権が失われ、**復旧する手段がない**。

| | 使うアカウント |
|---|---|
| テスト用グループ | 私物でよい（あとで捨てる） |
| **本番グループ** | **業務用の番号・端末で作ったアカウント。運営2人以上を常駐させる** |

### 2. グループ名

[D-003](decisions.md#d-003) で決めた形。
```
関西28卒バイトコミュニティ
関東28卒バイトコミュニティ
関西28卒バイトコミュニティ #2      ← 500人到達で分割したとき
```
社名も一柳も名前に出ないので、運営の存在感はノートの固定表示と発言で作る。

### 3. どの学年から開けるか

「関西・関東 × 27卒・28卒あたりから」という提案があるが、**いま（2026年9月）の学年はこうなる**。

| 卒年 | いまの学年 | 卒業まで | 性質 |
|---|---|---|---|
| **27卒** | 学部4年 | 約6ヶ月 | 授業が少なく**稼働力は高い**。ただし在籍が短く、紹介の連鎖が育つ前に抜ける |
| **28卒** | 学部3年 | 約1年半 | 就活の真っ最中。**在籍が長く、紹介が連鎖する時間がある** |
| **29卒** | 学部2年 | 約2年半 | いちばん長く使えるが、就活の当事者意識はまだ薄い |

紹介制コミュニティは「回すほど1人あたりの獲得コストが下がる」設計なので、
**在籍期間の長さが効いてくる**。27卒は半年で抜けるため、紹介の連鎖が回り始める前に卒業する。

**判断の材料**: 27卒を「いま稼働してくれる要員」として細く持ち、
28卒を「コミュニティを育てる本命」として厚くする、という配分が素直。
最初の入口リンク10本をどちらに何本配るか、という形で調整できる。

## 先に潰しておく — LINEログインチャネルの「開発中」

**LINEログインチャネルは作成直後「開発中」の状態にある。** このとき、
チャネルにロール（Admin / Tester）を持つ人しか登録画面を開けない。
外部の人が入口リンクを踏むと、こうなる。

```
400 Bad Request
This channel is now developing status. User need to have developer role.
```

**運営が自分で試すぶんには通ってしまうので、気づかない。** 外部の人に踏んでもらって初めて出る。
入口リンクを配ってから気づくと、配った全員が同じ画面で止まる。

**直し方**: LINE Developers コンソールで LINEログインチャネルを開き、
ページ上部の「開発中」をクリックして「公開済み」にする。

> ⚠️ 一度「公開済み」にすると「開発中」には戻せない。

なお LINE 側ではプライバシーポリシーURLは任意項目なので、公開自体は止まらない。
ただし登録画面は氏名・大学・生年月日を取るので、**外部に入口リンクを配り始めるのは
プライバシーポリシーの追記（構想メモ §8-4）が反映されてから**にする。
同意を取った記録と、リンク先の記載内容が食い違わないように。

## 通しながら確認する7点

順番に確認していくと、設計が意図どおり動いているかが分かる。

**①と⑥は運営のアカウントでは確認できない。** 協力してくれる外部の人がいる間に、
先にこの2つを済ませておくと二度手間にならない。

### ① 友だち追加していないと登録できないか

入口リンクを踏む前に、一柳を**友だち追加していない状態**で登録画面まで進めてみる。

**期待**: 「友だち追加をお願いします」で止まり、フォームが出ない。

ここが素通りできると、コミュニティの関所が機能していない。全員が一柳の友だちである
（＝1対1で連絡が取れる）ことが、以降のすべての前提になっている。

### ② 卒業年度の表示が正しいか ← いちばん事故りやすい

学年を選んだときに出る卒年を、**必ず目で確認する**。

| いま入れる学年 | 正しい表示 |
|---|---|
| 学部4年 | **27卒** |
| 学部3年 | **28卒** |
| 学部2年 | 29卒 |
| 修士2年 | 27卒 |
| 修士1年 | 28卒 |

> 「28卒」は**2028年3月に卒業する人**を指す。年度は4月始まりなので、
> 2027年度の学部4年生が2028年3月に卒業して28卒になる。
> `卒年 = 年度 + 卒業までの残り年数`（最終学年の残り年数は1）。

**1年ずれていると、全員が1つ違うグループに振り分けられる。**
静かに壊れるので、登録が通ったこと自体では気づけない。ここは必ず見る。

あわせて、**間違っていたときに本人が直せるか**も確認する。留年・休学・院進で必ずズレる人が出る。

### ③ グループ招待リンクが1対1で届くか

**期待**: 一柳との1対1トークに届く。

グループ側には出ないこと。招待リンクがグループに流れると、
そこにいる全員がコピペで転送できてしまう。

### ④ ダッシュボードに反映されるか

招待リンクからグループに入ったあと、🌱タブで**自分が「入室済み」**になっているか。

「招待済みで未入室」のまま止まるなら、入室の検知が効いていない。
これが動いていないと、あとで名簿とグループの実態がずれていく。

### ⑤ グループで発言しても一柳が反応しないか ← 誤爆確認

テストグループで、ふつうに何回か発言してみる。

**期待**: 一柳は**何も返さない**。

グループ内の発言は全部システムに届くので、設定を1つ間違えると全部に反応する。
場が死ぬので、ここは必ず確認する。返してよいのは入室時の歓迎メッセージだけ。

### ⑥ 未登録の人が入ったときに通知が来るか

**別のLINEアカウント**（もう1台、または知人に頼む）で、入口リンクを踏まずに
グループに直接招待して入ってもらう。

**期待**: 運営に通知が届く。

これが動いていれば、[D-002](decisions.md#d-002)（登録を依頼し、応じなければ退出）の運用に乗せられる。
届かないなら、直接招待された人が名簿に載らないまま増えていく。

### ⑦ 入口リンクを無効化すると使えなくなるか

発行した入口リンクを🌱タブで無効化し、そのリンクをもう一度踏む。

**期待**: 登録できない。

荒らされたときにそのリンクだけ止める、という運用の生命線。
既に登録済みの人には影響が出ないことも確認する。

## 詰まったときに伝えること

「動かない」だけだと原因が絞れない。この4つを添える。

1. **どの手順で**（①〜⑦のどれか、取扱説明書の何番か）
2. **画面に何が出たか**（文言をそのまま。スクリーンショットがあれば最良）
3. **自分のLINEアカウント**（どのアカウントで試したか。友だち追加済みかどうか）
4. **時刻**（ログを追う手がかりになる）

## 通ったあと

1. 業務用アカウントで本番グループを作る（運営2人以上を常駐）
2. 一柳を招待し、ダッシュボードで地域・学年・招待URLを設定
3. ノートにルールを掲示する
   ```
   ・案件の詳細と応募は一柳とのトーク（1対1）で受け付けます
   ・グループ内での勧誘・営業は禁止です
   ```
4. **運営メンバー3〜5人を先に入れる**（無人の場に最初の人を入れない）
5. 入口リンクを最初の10人に配る

以降の日々の回し方は [運用設計](operations.md) と
[運用ハンドブック](https://claude.ai/code/artifact/0dcd0b26-5c9f-4e7d-84a6-b557f66a708c) を参照。

## 運用を始める前に、もう1つ決めること

**グループへの投稿は、メンバー人数分の通数としてカウントされる。** 1通ではない。
500人グループへの1投稿は500通になる（[調査結果 §1](line-platform-research.md)）。

「告知の出し方」は三上さんの担当なので、**投稿頻度の上限を先に決めておく**とよい。

| 項目 | 案 |
|---|---|
| グループあたりの投稿上限 | 週2回 |
| 個別配信に切り替える基準 | 対象が全体の1/3以下に絞れる案件 |

あわせて、グループ投稿は「参加希望の方は一柳に『0904大阪』と送ってください」の形にすると、
以降のやりとりが**応答メッセージ扱いになり通数を消費しない**。
運営から一方的に送るぶんだけが課金される。
