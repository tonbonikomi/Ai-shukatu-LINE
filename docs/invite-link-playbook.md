# 入口リンクの使い方

ダッシュボード 🌱コミュニティ → 入口リンク タブの運用。
**拡大の速度はここで決まる**ので、いちばん手を入れる価値がある画面。

> 入口リンクは自動発行しない方針（[D-001](decisions.md#d-001)）。
> 誰に配るかを運営が選ぶ設計にしたので、**配り先の人選がそのまま拡大速度**になる。

---

## 1. リンクは2種類ある

発行画面の「紹介者の氏名」を**入れるか空にするか**で、まったく別物になる。

| | 記名リンク（氏名を入れる） | 汎用リンク（氏名を空） |
|---|---|---|
| 渡す相手 | 個人 | 不特定多数（Instagram・説明会・DMなど） |
| 紹介者 | 記録される | **付かない** |
| 紹介料 | 対象になる | 対象外 |
| 役割 | **増殖の入口** | **母集団の入口** |

**この2つは役割が違う。** 汎用リンクをいくら配っても、自己増殖のループには乗らない。
紹介の連鎖を作るのは記名リンクだけ。

### 汎用リンクを公開の場に置くときの注意

Instagramのプロフィールなど**公開の場に置いた瞬間、そこだけ「誰でも登録できる」状態**になる。
紹介制の建て付けがその1本ぶんだけ緩む、というトレードオフとして意識的に選ぶこと。

対策としては、**置く期間を決めて、終わったら無効化する**。
掲載をやめてもリンクは生き続けるので、放置すると出どころ不明の登録が入り続ける。

---

## 2. リンクは1人1本にする

10人に配るなら10本発行する。共有の1本を配り回さない。

1人1本にすると、これができる。

| | できること |
|---|---|
| **登録数** の列 | その人が実際に何人連れてきたかが見える |
| **無効化** | 荒らされたら、その人の分だけ止められる |
| 紹介料 | 誰にいくら払うかがそのまま出る |

共有の1本にすると、この3つが全部できなくなる。**あとから分離することもできない。**

---

## 3. メモ欄には「どこに置いたか」を書く

リンクは配った瞬間に手を離れる。1ヶ月後に「これ何のリンクだっけ」になるのが必ず起きる。

| リンクの種類 | メモの書き方 |
|---|---|
| 記名 | `関西28卒・9/9手渡し` — 属性と渡した日 |
| 汎用 | `Instagramプロフィール` `9/12説明会スライド` `送客LINE一斉案内 9/15` |

**汎用リンクは置き場所ごとに1本ずつ作る。** そうすれば「Instagramから何人、説明会から何人」が
登録数の列だけで分かる。1本を使い回すと、どこが効いたのか永久に分からない。

---

## 4. ⚠ 氏名は「登録済みの人」から選ぶ

発行画面にこう書いてある。

> 同名の登録があればその人に、無ければ紹介者として新しく作られる
> （承認待ちのまま＝配信や案件情報の対象にはならない）

ここから2つ、気をつけることがある。

### ① 紹介者にする人は、先に本人が登録を済ませていること

未登録の人の名前でリンクを発行すると、その人のレコードは**承認待ちのまま**作られる。
承認待ちは配信や案件情報の対象外なので、**その人自身には案件が流れない。**

「田中くんに友達を紹介してもらおう」とリンクだけ先に発行しても、
田中くん本人がコミュニティの外にいる状態になる。順番が逆。

```
正しい順番
  ① 本人に登録してもらう（別のリンクから、または運営が直接）
  ② 「参加者」タブでその人が登録済みなのを確認する
  ③ その氏名で入口リンクを発行する
```

### ② 同姓同名と表記ゆれで、別人に紐づく

紐づけは**氏名の一致**で行われる。つまり、

- **同姓同名**がいると、意図しない人の紹介として記録される
- 「田中太郎」と「田中 太郎」（スペースあり）は別人として扱われる可能性がある

人数が増えるほど確実に起きる。対策は2つ。

1. 発行前に「参加者」タブで検索し、**その氏名が1人しかいないことを確認する**
2. **姓名の間にスペースを入れるか入れないかを、最初に決めて統一する**

同姓同名が実際に出たら、メモ欄で区別する（`田中太郎（関西28卒）`）か、
さとみさんに「氏名でなく参加者を選ぶ形にできないか」を相談する。

## 5. 最初の10本をどう配るか

**ここの人選が、コミュニティの初期の質をそのまま決める。**
あとから薄めることはできても、濃くすることはできない。

### 選ぶ基準

| 見るところ | なぜ |
|---|---|
| ドタキャン・無断欠勤がない | その人の紹介する友達も似た層になる |
| 態度に問題がない | 排除したいのは「態度の悪い人」だけ（構想メモ §2） |
| **28卒を厚く** | 27卒は卒業まで約6ヶ月。紹介の連鎖が回る前に抜ける |
| 実際に稼働している | 稼ぐ実感がある人でないと友達に説明できない |

金目的の参加は許容する方針なので、「意識が高いか」は基準にしない。

### 配るときの文面

リンクだけ送っても踏まれない。何のリンクかを1行で言う。

```
バイト案件が流れる就活生のグループを作りました。
単発で入れる案件を週に何件か流していて、
条件のいいものは個別にご案内しています。

友達で興味ありそうな人がいたら、このリンクを送ってもらえますか。
{リンク}

このリンクから登録した人は、〇〇さんの紹介として記録されます。
```

> ⚠️ **「紹介したら◯◯円」という金額の話は、まだ書かないこと。**
> 紹介料の法的な建付けは弁護士確認が進行中で未確定（構想メモ §8-5）。
> 確定するまでは、金銭的な見返りを明示した文面を配らない。
> 記録は初日から取れているので、確定後に遡って支払える。

## 6. 週次で見るもの

見るのは **登録数の列** ひとつでいい。

| 状態 | 読み取り方 | やること |
|---|---|---|
| 登録数が伸びている | その人は機能している | 追加で配る相手を紹介してもらう |
| **2週間 0 のまま** | 配り先が外れている | 声をかけ直すか、配り先を入れ替える |
| 汎用リンクが 0 | その置き場所が効いていない | 掲載をやめて別の場所を試す |
| 急に増えた | 転送された可能性 | 「参加者」タブで属性を確認する |

自動発行しない方針を選んだ以上、**この見直しをしないと拡大が止まる**。
週次の作業に必ず入れること。

---

## 7. いま出ている練習用リンク

`三上透輝 / 練習 / 登録数 0` は通しテスト用。

通しテストが終わったら**無効化する**。テスト用が残っていると、
本番の記名リンクと混ざって登録数が読めなくなる。

本番の記名リンクは、テストが通ってから改めて発行し直す。
